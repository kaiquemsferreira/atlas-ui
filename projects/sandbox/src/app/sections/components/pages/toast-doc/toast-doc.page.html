Components / Notifications

Toast

Notificações temporárias para feedback de ações do usuário. Suporta variantes, ações, detalhes expansíveis e posições.

Examples

Use os botões acima para disparar diferentes tipos de toast. Passe o mouse para pausar a barra de duração.

Info
Mensagem simples para informação.
Success
Confirmação + ações (ex: desfazer).
Warning
Atenção para validação/risco.
Error
Erro persistente (duration 0) com ação de retry.

API

Os métodos seguem o padrão: info/success/warning/error(message, options). 

notifications.success('Arquivo enviado!', {
          title: 'Upload successful',
          details: 'invoice.pdf foi enviado e indexado...',
          position: 'bottom-center',
          actions: [
    { label: 'Desfazer', variant: 'primary', onClick: () => ..., closeOnClick: true }
  ],
  durationMs: 6000
});
